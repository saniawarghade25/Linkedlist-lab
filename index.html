Deep Dive & Technical Analysis

The Standard Linked List Addition Algorithm

Explore the exact algorithm used in top technical interviews, why reverse digit storage simplifies arithmetic, and how to handle edge cases like unequal lengths and final carries.

💡 Why Reverse Order?

In standard elementary school arithmetic, we add numbers starting from the rightmost digits (the units place $10^0$) and proceed leftward, carrying over any overflow ($\ge 10$) to the next higher place value ($10^1, 10^2, \dots$).

Singly linked lists can only be traversed forward in $O(1)$ from head to tail. By storing numbers with the least significant digit at the head:

  • Immediate Alignment: Both list heads correspond to the units place ($10^0$). No list reversal or recursion needed!
  • Natural Carry Propagation: As we advance curr = curr.next, we naturally move to the next higher power of 10.
  • Arbitrary Precision: Can add numbers with 100+ digits without standard integer 64-bit overflow!
🔑 The Dummy Head Technique

Using a dummy head node (const dummy = new ListNode(0)) avoids special-casing the insertion of the very first node, simplifying list construction and preventing null pointer errors. At the end, simply return dummy.next.

📋 Algorithmic Invariants

1
Initialize Pointers and Carry:

Create a dummy node, set curr = dummy, and set carry = 0.

2
Traverse While Active:

Loop while l1 !== null || l2 !== null || carry !== 0. Notice the condition includes carry !== 0 so that a final leftover carry generates an additional node!

3
Extract Digits & Compute Sum:

v1 = l1 ? l1.val : 0 and v2 = l2 ? l2.val : 0.
Then: sum = v1 + v2 + carry.

4
Update Carry and Append Node:

carry = Math.floor(sum / 10).
curr.next = new ListNode(sum % 10); advance curr = curr.next.

5
Advance Input Pointers:

Advance l1 = l1.next (if not null) and l2 = l2.next (if not null).

6
Return Result:

Return dummy.next, which is the head of the newly constructed sum list.

// Standard LeetCode #2: Add Two Numbers Represented by Linked Lists
function addTwoNumbers(l1: ListNode, l2: ListNode): ListNode {
    // Step 1: Create a dummy head to anchor the result list
    let dummy = new ListNode(0)
    let curr = dummy
    let carry = 0

    // Step 2: Loop while any list has nodes OR carry is non-zero
    while (l1 != NULL || l2 != NULL || carry > 0) {
        // Step 3: Extract digits (substitute 0 if list is exhausted)
        let digit1 = (l1 != NULL) ? l1.val : 0
        let digit2 = (l2 != NULL) ? l2.val : 0

        // Step 4: Calculate sum and new carry
        let totalSum = digit1 + digit2 + carry
        carry = floor(totalSum / 10)
        let outputDigit = totalSum % 10

        // Step 5: Append new node and advance pointers
        curr.next = new ListNode(outputDigit)
        curr = curr.next

        if (l1 != NULL) l1 = l1.next
        if (l2 != NULL) l2 = l2.next
    }

    // Step 6: Return the result list starting after the dummy head
    return dummy.next
}
/**
 * Definition for singly-linked list node.
 * function ListNode(val, next) {
 *     this.val = (val===undefined ? 0 : val)
 *     this.next = (next===undefined ? null : next)
 * }
 */

class ListNode {
  constructor(val = 0, next = null) {
    this.val = val;
    this.next = next;
  }
}

function addTwoNumbers(l1, l2) {
  const dummyHead = new ListNode(0);
  let current = dummyHead;
  let carry = 0;

  while (l1 !== null || l2 !== null || carry !== 0) {
    const val1 = l1 !== null ? l1.val : 0;
    const val2 = l2 !== null ? l2.val : 0;
    
    const sum = val1 + val2 + carry;
    carry = Math.floor(sum / 10);
    
    current.next = new ListNode(sum % 10);
    current = current.next;

    if (l1 !== null) l1 = l1.next;
    if (l2 !== null) l2 = l2.next;
  }

  return dummyHead.next;
}
Time Complexity O(max(m, n))

Where m and n represent the number of nodes (digits) in List 1 and List 2 respectively.

  • Single Simultaneous Pass: The algorithm executes exactly $\max(m, n)$ iterations when there is no carry-out at the highest place value, or $\max(m, n) + 1$ iterations when a final carry occurs (e.g. $999 + 1 = 1000$).
  • Constant Time per Step: Node value access, addition, division, modulo, and pointer updates take strictly $O(1)$ constant time per iteration.
  • Total Bound: $\max(m, n) + 1 \in \mathcal{O}(\max(m, n))$, which is optimal because every digit must be inspected at least once.
Space Complexity O(max(m, n))

The length of the newly created result linked list is at most $\max(m, n) + 1$.

  • Output Space: We allocate memory for a new linked list containing exactly $\max(m, n)$ nodes (or $\max(m, n) + 1$ nodes if a final carry generates a new leading digit).
  • Auxiliary Space: Aside from the required output list nodes, only a constant number of pointer variables (dummy, curr, carry, val1, val2) are maintained, using $O(1)$ extra auxiliary memory.
  • Total Space: $\mathcal{O}(\max(m, n))$ total space.
